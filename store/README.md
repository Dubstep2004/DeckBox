# Магазин шаблонов DeckBox

Здесь лежат готовые наборы страниц для панели. Их видно в настройках DeckBox: **PRO › Магазин шаблонов**.

## Как добавить свой шаблон

1. Соберите страницы в настройках DeckBox.
2. В разделе «Дополнительно» откройте JSON настроек и скопируйте нужные страницы (`pages`).
3. Добавьте свой набор в [`store.json`](store.json) в массив `packs`:

```json
{ "id": "my-pack", "name": "Мой набор", "icon": "⭐", "author": "ваш ник на GitHub",
  "desc": "Коротко: что внутри.", "pages": [ { "title": "Страница", "icon": "📄", "widgets": [ … ] } ] }
```

4. Пришлите pull request. После принятия набор появится у всех пользователей сам, без обновления программы.

Сетка страницы — 12 × 6 клеток; у каждого виджета есть `type`, `x`, `y`, `w`, `h` и необязательные `options`.
